YOUR BUILD-IT-BY-DOING-IT GUIDE

Learn the tools behind EGOtracker.

Follow the path from one local expense to a secure cloud app. Each step builds on the one before it.

01

NETWORKING

Trace one request

Open your browser's Network panel and add an expense. Follow the browser's fetch to POST /api/expenses, the Express route, Prisma Client, SQLite, and the JSON response.

Notice the host (localhost), port (3000), HTTP method, headers, status code, and JSON body. On the public internet, DNS finds a host and HTTPS/TLS encrypts the connection.

02

PRISMA ORM

Change the data model

Open prisma/schema.prisma. Add a nullable field to Expense, then create a migration:

npm run db:migrate -- --name add-field

Read the generated SQL in prisma/migrations/. Find findMany, create, and deleteMany in the API and inspect saved records with Prisma Studio.

03

GIT & GITHUB

Work in small changes

Make a feature branch, inspect your diff, commit only the intended files, and push it to GitHub:

git switch -c feat/my-change
git status
git add src/app.js
git commit -m "Describe my change"
git push -u origin feat/my-change

Open a pull request, review the diff and checks, then merge. Keep .env, AWS keys, and database files out of Git.

04

ACTIONS & DEVSECOPS

Make safety repeatable

Inspect .github/workflows/ci.yml. Pushes and pull requests run Prisma schema validation, API tests, and an npm dependency audit.

Try a test that fails, push it on a branch, and follow the red check in the Actions tab. Fix it and confirm the green check. Then enable secret scanning and Dependabot, and require checks before merging.

05

AWS DEPLOYMENT

Move to the cloud deliberately

First learn IAM roles, VPCs, subnets, security groups, DNS, and TLS. A production-shaped path is:

Browser→CloudFront + S3→API (App Runner / ECS)→Private RDS PostgreSQL

SQLite is for local learning; it is not the shared, durable database for a multi-instance deployment. Migrate Prisma to PostgreSQL, keep the database private, store its URL in Secrets Manager, and give the API only the access it needs.

When ready, automate deployment with GitHub Actions using OIDC and a narrowly scoped IAM role—never a long-lived AWS key in GitHub secrets. Set billing alerts before creating paid resources.

Ready to try it? Start the app with npm run dev and pick one small lesson.
